You type youtube.com and press Enter

2

localhost:4000 — your Node.js server

How your OS binds a port → loopback interface (127.0.0.1) → TCP socket → Node.js event loop picks up the connection → your route handler runs → response flows back. Why port <1024 needs sudo. Why two processes can't share a port.

~8 steps · Every dev's daily mystery

3

You click "Sign in with Google"

OAuth 2.0 authorization code flow → HTTPS keeps it safe → Google issues an auth code → your server exchanges it for tokens → JWT structure (header.payload.signature) → cookie vs. localStorage → session vs. stateless auth. Why you should never roll your own auth.

~9 steps · Auth is broken everywhere

4

git push → live in production

Git push triggers webhook → CI runner clones repo → builds Docker image → pushes to ECR → Kubernetes rolling deploy → readiness probe passes → load balancer shifts traffic → old pods terminated. Zero-downtime deploy explained step by step.

~10 steps · The deploy pipeline most devs never see

5

SELECT * FROM users WHERE id = 42

Connection pool checkout → query parser → planner picks an index scan vs. full table scan → B-tree walk → buffer pool (avoid disk if cached) → row fetch → serialisation → result set back to app. Why N+1 queries kill performance.

~9 steps · What actually makes queries slow

6

You upload a photo to Instagram

Browser multipart/form-data → server receives stream → generates presigned S3 URL → direct browser-to-S3 upload (bypassing your server) → S3 triggers Lambda → image resized to 4 variants → CloudFront CDN invalidated → URL stored in DB.
